\section{Data and Code Availability}
\label{sec:data_availability}

Rugby union KPIs were supplied by Oval Insights through access arranged with Scarlets RFC and are not redistributed. Football KPIs were analysed under agreement with Swansea City AFC and are not redistributed. Supporting-domain provenance is described in Methods (\cref{sec:methods}).

All PEF estimates, class separations, and $\Delta\mathrm{ML}$ values in this manuscript were produced by \path{scripts/paper_pipeline/run_paper_pipeline.m} in {MATLAB} {R2025b} with the Statistics and Machine Learning Toolbox. Team-blocked fold construction is described in Methods (\cref{sec:ml_cv}). A de-identified per-KPI table, with no match rows, is written to \path{scripts/paper_pipeline/outputs/referee_kpi_summary.csv}. Interactive tools for the analytic probit surface are available at \url{https://github.com/AroundInteger/pef-tools}.
